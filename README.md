# Aggregate-then-Conformalize: Efficient Online Conformal Prediction with Super Learner Ensembling

Reliable uncertainty quantification in streaming environments requires methods that are not only valid under distribution shifts but also statistically efficient. While Online Conformal Prediction (OCP) provides robust distribution-free coverage guarantees, its performance is often bottlenecked by the accuracy of a single underlying model. The rich availability of base learners in modern machine learning motivates the need for aggregation strategies that can translate model diversity into improved conformal efficiency. In this work, we propose a simple yet powerful ``aggregate-then-conformalize'' framework that integrates OCP with an Online Super Learner. Unlike existing ensemble methods such as Conformal Online Model Aggregation (COMA), which aggregates prediction sets (``conformalize-then-aggregate''), our method optimally combines heterogeneous base predictors \textit{before} constructing confidence intervals. Theoretically, we prove that this strategy maintains finite-sample validity while asymptotically achieving higher efficiency (yielding  narrower intervals) than both individual base learners and the COMA baseline. Empirical evaluations on synthetic jump-diffusion processes and real-world datasets corroborate these findings, establishing Super Learner ensembling as a practical standard for efficient online uncertainty quantification.
